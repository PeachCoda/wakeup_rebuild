# FakeUp 网页课表

一个面向手机使用的杭电课表网页。

## 功能

- 显示课表、切换教学周、显示/隐藏非本周课程
- 登录上课啦并同步课表
- 上课啦密令签到
- 自定义背景、导出课表图片
- PWA 安装到桌面

## 上课啦签到鉴权

签到没有绕过官方鉴权。流程是：

1. 用户先在 FakeUp 登录上课啦账号。
2. 后端保存本站会话，并刷新/获取上课啦登录态。
3. 提交密令时，前端获取定位，并通过官方阿里验证码 SDK 生成一次性 `captchaVerifyParam`。
4. 后端带着上课啦 token、密令、定位和验证码参数调用上课啦正式签到接口。

验证码参数由官方 SDK 生成，签到结果来自上课啦接口返回。

定位由浏览器提供，隔一段时间后首次获取可能较慢；再次打开通常会命中系统缓存。

## 安全说明

适合自己或熟人小范围使用。后端会保存用于刷新上课啦登录态的信息，请保护好服务器和数据目录，不要开放给不可信用户。

## 文件

- `index.html` / `styles.css` / `app.js`：前端
- `server/skl-proxy.mjs`：上课啦后端代理
- `deploy/`：Nginx 和 systemd 示例配置
- `sw.js`：PWA 缓存
