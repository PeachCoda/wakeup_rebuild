# WakeUp 课表功能范围拆解

从 APK 的 `AndroidManifest.xml`、布局文件和中文字符串能看出，WakeUp 课程表相关模块主要包括以下部分：

- 主课表：周视图、日期栏、节次栏、课程格子、空课表状态、切换周数
- 课程编辑：课程名称、颜色、学分、周数、节次、自定义时间、教室、老师、备注
- 课程详情：周数、时间、地点、老师、学分、备注、编辑、复制、删除、冲突提示
- 课表设置：开学时间、当前周、学期周数、一天节数、课程格子高度、周末显示、非本周课程显示、节次栏时间
- 时间表：选择时间表、编辑每节课上下课时间
- 多课表：新建课表、切换课表、管理课表
- 数据流转：导入课表、导入反馈、文件导入、HTML/Excel 导入
- Android 特性：课程提醒、今日课程通知、一周课程小组件、今日课程小组件

本项目的第一版保留课表软件最核心的学习闭环：

- 周视图渲染
- 课程增删改查
- 周数与单双周规则
- 节次时间配置
- 多课表和本地保存
- JSON 导入导出

暂不实现的部分：

- 教务系统登录和解析
- 搜题、作业、广告、会员、支付
- Android 通知、小组件和后台服务
- WakeUp 的图片、图标、动画、文案与内部代码
